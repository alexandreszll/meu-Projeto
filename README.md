# VidaPlena Saúde — Clínica de Saúde

## Sobre o projeto

O VidaPlena Saúde é uma landing page estática desenvolvida para uma clínica de saúde fictícia.

O projeto apresenta os principais serviços oferecidos pela clínica, sua equipe de profissionais e um formulário de contato para os visitantes.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Node.js
* Express

## Funcionalidades

* Apresentação da clínica
* Exibição de serviços de saúde
* Apresentação da equipe profissional
* Formulário de contato
* Layout responsivo para diferentes tamanhos de tela

## Como executar o projeto

1. Instale o Node.js.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o terminal do VS Code.
4. Execute:

```bash
node server.js
```

5. Abra o navegador e acesse:

```text
http://localhost:3000
```
